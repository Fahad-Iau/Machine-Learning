# Lab 2 — Exploratory Data Analysis (EDA)

## 📌 Overview
This lab focuses on Exploratory Data Analysis using a real-world housing dataset. The goal is to understand the data's structure, distributions, and relationships before applying any machine learning model.

## 🎯 Objectives
- Load and inspect a real-world dataset (King County House Sales)
- Perform statistical summaries and data exploration
- Identify patterns, correlations, and potential issues in the data
- Visualize data distributions and feature relationships

## 📊 Dataset — King County House Sales (`kc_house_data.csv`)
| Column | Description |
|--------|-------------|
| `price` | Sale price of the house |
| `bedrooms` | Number of bedrooms |
| `bathrooms` | Number of bathrooms |
| `sqft_living` | Square footage of living space |
| `sqft_lot` | Square footage of the lot |
| `floors` | Number of floors |
| `waterfront` | Whether the house has a waterfront view |
| `grade` | Overall grade given to the house |
| `yr_built` | Year the house was built |
| ... | Additional features |

## 🛠️ Tools & Libraries
- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🚀 How to Run
1. Ensure `kc_house_data.csv` is in the same directory as the notebook
2. Launch Jupyter: `jupyter notebook`
3. Open `Lab 2 .ipynb`
4. Run cells sequentially with `Shift + Enter`

## 📚 Key Concepts
- `.describe()`, `.info()`, `.isnull()` for data inspection
- Correlation heatmaps
- Distribution plots and histograms
- Feature relationship analysis
