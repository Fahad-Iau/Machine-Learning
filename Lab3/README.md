# Lab 3 — Data Visualization with Matplotlib

## 📌 Overview
This lab dives into data visualization — one of the most critical steps in any machine learning pipeline. Using Matplotlib and the King County housing dataset, this lab builds skills in creating clear, informative charts and plots.

## 🎯 Objectives
- Create a variety of chart types using Matplotlib
- Visualize feature distributions and relationships in the housing dataset
- Use visualization to derive insights and support decision-making
- Build readable, well-labeled plots for reporting

## 📊 Dataset
Same King County House Sales dataset from Lab 2 (`kc_house_data.csv`), explored further through visual analysis.

## 🛠️ Tools & Libraries
- Python 3.x
- Matplotlib
- Pandas
- NumPy
- Seaborn *(optional)*

## 🚀 How to Run
1. Ensure `kc_house_data.csv` is in the same folder as the notebooks
2. Launch Jupyter: `jupyter notebook`
3. Open `1- Data Visualization - Matplotlib-Fahad.ipynb` to start
4. Run cells sequentially with `Shift + Enter`

## 📚 Key Concepts
- Line plots, bar charts, scatter plots, histograms, box plots
- Customizing plots: titles, labels, legends, colors
- Subplots and figure layout
- Visualizing correlations and distributions
